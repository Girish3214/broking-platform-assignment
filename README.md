# Broker Platform - Frontend

A stock broker platform interface with:

✅ Broker login  
✅ Bottom navigation  
✅ Holdings, Orderbook, Positions screens  
✅ Buy/Sell Order Pad  
✅ Draggable FAB  
✅ Mocked API responses

---

## 🔧 Tech Stack

- React + TypeScript
- Tailwind CSS
- React Router
- Axios (mock API)
- Context API (auth)

---

## 🚀 Run Locally

```bash
npm install
npm start
```
